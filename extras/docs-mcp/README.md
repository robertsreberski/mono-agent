# @mono-agent/docs-mcp

## Category

Category: `context`

Plugin tier: this package releases in the mono-agent lockstep but stays outside
the default `@mono-agent/agent-app` dependency closure.

## Responsibility

Provides version-matched, offline semantic and exact-identifier search over the
canonical mono-agent documentation and the authoritative `mono-agent-composer`
references through one read-only MCP tool.

## Install / Usage

Pair the exact version matching `@mono-agent/agent-app`:

```bash
MONO_AGENT_VERSION="$(mono-agent --version)"
MONO_AGENT_VERSION="${MONO_AGENT_VERSION#mono-agent }"
npx -y "@mono-agent/docs-mcp@$MONO_AGENT_VERSION"
```

`mono-agent install-skill` configures the server for available Codex and Claude
Code installations by default. To register it manually:

```bash
codex mcp add mono-agent-docs -- npx -y "@mono-agent/docs-mcp@$MONO_AGENT_VERSION"
claude mcp add --scope user mono-agent-docs -- npx -y "@mono-agent/docs-mcp@$MONO_AGENT_VERSION"
```

The executable speaks MCP over stdio with no flags. `--check` validates the
bundled corpus and runs a representative query; `--version` prints package,
corpus, and embedding-model versions as JSON.

The MCP surface is:

- Tool `search_mono_agent_docs`, accepting `query`, optional `limit` (1–8),
  and optional `scope` (`all`, `composer`, or `docs`). It returns full Markdown
  excerpts plus structured provenance and resource links.
- Resource template `mono-agent-docs://chunk/{chunkId}`, returning the exact
  versioned Markdown chunk selected by search.

## Dependency Boundary

Depends on the MCP TypeScript SDK, Zod for wire-schema validation, and the
exact-pinned `@yarflam/potion-base-8m@1.0.4` package. The model and precomputed
corpus are local; runtime search performs no network calls and writes no state.
There are no dependencies on other `@mono-agent/*` packages.

## What This Package Does Not Own

It does not host the documentation website, mutate agent configuration, crawl
source code, select a runtime model, or replace the composer references. The
website remains the human reader surface; the bundled composer references remain
the version-specific fallback when an MCP client is unavailable or mismatched.
