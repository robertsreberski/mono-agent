## Rejected freeze-blockers (with reason)

- **A2-1 (Supermemory liveness)** → P1, not blocking. Opt-in non-default backend; the `ok` line

  falsified for any default config. Real consistency fix, not a freeze gate.
- **A2-2 (`readiness-probe-worker.ts` test coverage)** → P2, not blocking. Missing test coverage of
  a path that works correctly in production ≠ a shipped defect. No catastrophe, no DoD clause.
- **A3-1 (`preserveMcpServersUnderOverride` test coverage)** → P1, not blocking. Security boundary
  code is correct and in production; the gap is missing tests (regression *risk*), not a live hole.

## Cross-artifact contradictions

- **A3 F2 vs E2 scope.** A3 declares `attestManagedBackgroundRuntime` dead; E2's coverage note
  (E2-scripts-ci-release.md:106) records reading `managed-runtime-attestation-probe.mjs` — the exact
  script that calls it. Synthesis MUST drop A3 F2 / A3-2 and not double-count it as dead code.
- **Duplication triad (A1 F3 / A2 F3 / A3 F4).** Three artifacts independently flag "one hardened
  primitive implemented N times" (atomic-write ×2, redaction ×2, owner-private lock ×4). Not
  contradictory — a single cross-cutting anti-pattern. Synthesis should merge into one theme:
  *this package repeatedly hand-rolls hardened filesystem/security primitives instead of sharing them.*
