## Confirmed freeze-blockers

1. **A-C2-1 / C2-F1 — License coherence for a plugin-open v1.** No root LICENSE; all 20 published non-kernel packages are `UNLICENSED` (grant zero downstream rights) while the vendored kernel is `GPL-3.0-only` and the ADR states "mono-agent is GPLv3." A publicly-published, plugin-open framework cannot make its plugin-open premise legally real under these terms. Fix = maintainer license decision + root LICENSE + consistent per-package `license` fields + ADR reconciliation. (Amended: NOT a GPL-violation catastrophe — single copyright owner — but decisive for the plugin-open premise.)

## Rejected freeze-blockers (downgraded)

1. **C1-1 / C1-F1 — harness channel misclassification → P1, non-blocking.** Real correctness bug but scoped to WhatsApp (extras-tier) as the only genuine functional miss; OpenAI-API is correctly classified, TUI is near-harmless. Degrades one opt-in channel + undermines plugin-open framing, but no catastrophe and does not make honest ops false. Fix before/around v1, not a freeze gate.
2. **A-C2-2 / C2-F2 — sandbox spread-order override → P2, non-blocking.** Latent, no triggering call site, fail-closed default, degenerate threat model (only the host author can pass the colliding key). One-line hardening; not a v1 blocker.

## New findings (from re-reading code)

- **NEW-1 (P3, informational — refutation corollary).** Two distinct config-write paths coexist with asymmetric concurrency safety: the **conversational proposal path** (`local-configuration.ts`) has full optimistic-concurrency via the `version`/`sha256` CAS token (refuting C1-F3), whereas the **direct merge path** (`writeSettingsJson`/`writeMonoAgentConfigJson`, used by channel-adapter config setup and `init`) does an unconditional read-merge-write with no CAS (last-writer-wins). This is the *only* residual kernel of truth in the (otherwise refuted) C1-F3, and it is minor: the direct writers run at setup/init time and are not normally concurrent with the live proposal flow. Not actionable for v1 on its own; noted so synthesis does not resurrect C1-F3's stronger (false) claim.
- No other new defects surfaced during verification. All other spot-read code (redaction UTF-8 walk-back, commitTerminal single-write invariant, sandbox fail-closed passthrough) was sound.
