# Downloads Curator Demo

This demo starts a TUI-connected agent scoped to the user's Downloads folder.
It defaults to `~/Downloads`, runs through the Codex app runtime, and exposes a
curated MCP server for listing, proposing, and applying cleanup actions.

The agent cannot permanently delete files. Trash actions move files to the
user's Trash folder, and every move or trash action must be applied through an
explicit approval phrase generated by `downloads_create_proposal`.

## Run

```bash
pnpm run build:demo
pnpm run demo:downloads
```

Useful options:

```bash
pnpm run demo:downloads -- --downloads ~/Downloads
pnpm run demo:downloads -- --model gpt-5.5
```

Generated local state is ignored by git:

```text
.mono-agent/downloads-curator/
```

## Tools

- `downloads_list` returns top-level Downloads entries with metadata and
  category hints.
- `downloads_create_proposal` writes a pending proposal and returns the exact
  approval phrase.
- `downloads_apply_proposal` revalidates selected actions and applies only
  explicitly approved action ids.
