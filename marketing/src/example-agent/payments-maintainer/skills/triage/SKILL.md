# Triage

1. Read the failing assertion and the code it tests.
2. Run just that test from `../payments-service`. Put test output in `scratch/`.
3. When I ask for the full suite in chat, run it in the background and report back here.
4. Tell me what broke, what points to it, and what you’d check next.
